# App Icon Generator

## Quick Start

To generate the app icons for Aurora's Letter Adventure:

1. Open `generate-icons.html` in any web browser
2. Icons will automatically appear on the page
3. Right-click on each icon preview
4. Select "Save Image As..."
5. Save as:
   - `icon-192.png` → `../assets/images/icon-192.png`
   - `icon-512.png` → `../assets/images/icon-512.png`

## Or Use the Download Buttons

Each icon has a "Download" button below it that will automatically download the file with the correct filename.

## Icon Design

The icons feature:
- Aurora's Rainbow gradient background (Sky Blue → Purple Magic → Bubble Pink)
- Large white letter "A" (for Aurora and Alphabet)
- Black stroke outline for visibility
- Optimized for both Android and iOS home screens

## Manual Icon Creation (Optional)

If you prefer to create custom icons:

1. Create a 512x512 PNG image
2. Use Aurora's Rainbow colors (#00BCD4, #9C27B0, #FF4081)
3. Add recognizable letter/education imagery
4. Save as both 192x192 and 512x512 versions
5. Place in `assets/images/` directory

## Testing PWA Installation

After generating icons:

1. Test on Chrome: Visit the game URL and look for "Install" button in address bar
2. Test on mobile: Open in browser and use "Add to Home Screen"
3. Verify the icon appears correctly on your home screen

## Troubleshooting

**Icons don't appear in browser:**
- Make sure you're opening the HTML file in a modern browser (Chrome, Firefox, Edge, Safari)

**Download button doesn't work:**
- Try right-clicking the canvas image and using "Save Image As..." instead

**Icons look blurry on home screen:**
- Ensure you saved both the 192x192 AND 512x512 versions
- Check that filenames match exactly: `icon-192.png` and `icon-512.png`
